## 2. Финальная идея: AI Photo Avatars

**Что это**: пользователь загружает 10-20 своих фото → платит → через 60-90 минут получает архив с 100+ профессиональными аватарками в разных стилях (LinkedIn, Tinder, корпоративные хедшоты, креативные стили и т.д.).

**Технология**: Flux Dev + LoRA fine-tuning через Replicate API (даёт лучшее сходство, чем SDXL).

**Скоринг**: 7/10 по фильтрам — единственная идея из 15+ исследованных, прошедшая все критерии.

## 4. Юридическая база (РФ)

### 152-ФЗ (Персональные данные)
- **Нужно**: регистрация как оператор ПДн в РКН (бесплатно, ~7 дней)
- **Нужно**: отдельное согласие на обработку фото
- **Нужно**: хранить данные на серверах в РФ → **Yandex Object Storage** (S3-совместимый)

### 572-ФЗ (Биометрия)
- **НЕ применяется** — мы не делаем идентификацию/аутентификацию по фото
- Это не биометрические ПДн в смысле закона
- Достаточно политики конфиденциальности и согласия

## 5. Технический стек (финальный)

```
Frontend:
  - Tilda (лендинг)
  - HTML страница загрузки фото (после оплаты) — S3 presigned URL

Backend (~400 строк Python):
  - FastAPI
  - SQLite (для 20-100 заказов/месяц достаточно)
  - BackgroundTasks (не нужен Redis на старте)

Сторадж:
  - Yandex Object Storage (152-ФЗ требование)

ML:
  - Replicate API
  - Модель: ostris/flux-dev-lora-trainer

Платежи:
  - ЮKassa + СБП
  - 3-5 рабочих дней на верификацию

Email:
  - Yandex SMTP (бесплатно до 500/день)

Хостинг:
  - Yandex Cloud Serverless Functions ИЛИ VPS 300₽/мес
```

### Архитектура потока

```
[Tilda лендинг]
      ↓
[ЮKassa оплата]
      ↓
[Редирект на страницу загрузки фото]
      ↓
[Upload в Yandex S3 через presigned URL]
      ↓
[Webhook /payment-success запускает pipeline]
      ↓
[Replicate: LoRA тренинг ~20 мин]
      ↓
[Replicate: 96 генераций × 8 стилей, параллельно ~30-40 мин]
      ↓
[Zip → Yandex S3 → подписанная ссылка]
      ↓
[Email клиенту со ссылкой на скачивание]
```

### Ключевой код (скетч)

```python
# webhooks.py
@app.post("/webhook/yukassa")
async def payment_webhook(request: Request, background_tasks: BackgroundTasks):
    data = await request.json()
    if data["event"] == "payment.succeeded":
        order_id = data["object"]["metadata"]["order_id"]
        order = db.get_order(order_id)
        background_tasks.add_task(run_pipeline, order)
    return {"status": "ok"}

# pipeline.py
async def run_pipeline(order: Order):
    # 1. Тренируем LoRA
    training = replicate.trainings.create(
        version="ostris/flux-dev-lora-trainer:...",
        input={
            "input_images": order.photos_zip_url,
            "trigger_word": "TOK",
            "steps": 1000,
            "lora_rank": 16,
        },
        destination=f"username/user-{order.id}"
    )

    # 2. Polling до завершения (~20 мин)
    while training.status not in ["succeeded", "failed"]:
        await asyncio.sleep(30)
        training.reload()

    # 3. Генерация 96 изображений
    STYLES = [
        "professional headshot of TOK, business suit, studio lighting",
        "casual portrait of TOK, modern office background",
        "TOK speaking at conference, confident pose",
        "linkedin photo of TOK, neutral grey background",
        "creative portrait of TOK, dramatic lighting",
        "outdoor portrait of TOK, natural light",
        "TOK in smart casual, coffee shop background",
        "executive headshot of TOK, dark suit, premium feel",
    ]

    tasks = []
    for style_prompt in STYLES:
        for _ in range(12):
            tasks.append(generate_image(order.id, style_prompt))

    results = await asyncio.gather(*tasks)

    # 4. Zip + S3 + email
    zip_url = await create_and_upload_zip(order.id, results)
    await send_completion_email(order.email, zip_url)
```

## 6. План запуска (черновой, ~35k₽)

### Неделя 1-2: Код
- Пишем backend с Claude Code (FastAPI + Replicate + S3 + email)
- Тестируем на своих фото (~$5 на Replicate)
- Деплоим на VPS / Yandex Cloud Functions
- **Затраты**: ~500₽ (тесты) + 300₽/мес (хостинг)

### Неделя 2-3: Юр. база + платежи
- Регистрация ИП / самозанятость
- Регистрация оператора ПДн в РКН (бесплатно, 7 дней)
- Подключение ЮKassa (3-5 раб. дней на верификацию)
- Политика конфиденциальности + согласие на обработку фото
- **Затраты**: 0-1000₽ (госпошлины если ИП)

### Неделя 3: Лендинг
- Tilda лендинг с примерами работ
- Форма загрузки фото (своя HTML или Typeform/Tally)
- Подключение ЮKassa
- **Затраты**: Tilda Personal 750₽/мес

### Неделя 4: Маркетинг и первые клиенты
- 5,000-10,000₽ на Яндекс.Директ (поисковые запросы: "фото для linkedin", "корпоративные хедшоты")

## 11. Ключевые риски

- **Replicate доступность**: API доступен из РФ? Если нет — нужен прокси / реверс через зарубежный сервер.
- **Платёжная инфра**: ЮKassa может отказать новому ИП без оборотов — резервный вариант Tinkoff/Робокасса.
- **Качество LoRA**: 1000 шагов тренинга может давать переобучение. Нужен тест на 5-10 разных людях до запуска.
- **Конкуренция**: Pieter Levels-стиль продукты появляются быстро, кто-то может запустить русскую версию параллельно. Преимущество — скорость выхода.
- **Соответствие 152-ФЗ при использовании Replicate**: данные уходят за рубеж. Нужно либо описать это в согласии (с явным OK от пользователя), либо рассматривать локальный inference (GPU-аренда в Selectel, дороже).
